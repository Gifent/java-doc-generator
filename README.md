# JavaDocumentGenerator
## Описание
Этот проект представляет собой генерацию документации на основе анализа .java файлов. Анализ осуществляется путем выявления специальных комментариев, а также общей информации о классах, методах, параметрах и т.д. Продукт удобен для использования новому разработчику, желающему быстро и легко изучить архитектуру проекта.

## Инструкция по установке

1. Клонируйте репозиторий:

  '''bash 
  git clone https://github.com/Gifent/java-doc-generator
  '''

2. Перейдите в директорию проекта:

  '''bash
  cd JavaDocGenerator
  '''

3. Запустите проект:

  '''bash
  java -jar target/java-doc-generator-1.0-SNAPSHOT.jar
  '''

## Список использованных библиотек

- [JavaParser](https://javaparser.org/) (3.27.1)
